# 进入刷写模式详解

## 常规方法（推荐）

1. **有线连接**：用数据线把手柄接到电脑主机 USB 口。
   - 只用充电线、扩展坞、Hub 都可能失败；请用**原装数据线直连主机**。
2. **确认正常模式**：手柄 1 号灯亮，电脑「设备和打印机」里能看到
   `Xbox 360 手柄` / `XBOX 360 Controller`。
3. **长按组合键**：同时按住 **HOME + X + Y** 约 **3 秒**不要松手，
   期间手柄会关机（灯灭）。
4. **观察设备**：手柄灯灭后约 1~3 秒，电脑设备管理器（或“磁盘”列表）中
   出现 **`BR23 UBOOT1.00`** 设备。
5. 松开按键，回到刷写工具操作。

> 提示：某些电脑需要 5~10 秒才会枚举出 `BR23 UBOOT1.00`，耐心等几秒。

## 为什么需要这个组合键？（原理）

反编译分析表明，手柄固件在主循环中检测：

- 1 号灯（有线模式）已点亮；
- X、Y 两个按键同时处于按下状态；
- 上述条件连续保持约 **0x84 = 132 个轮询周期（约 3 秒）**；
- 并且没有其它组合键冲突；

满足后固件调用 `FUN_01e01d94`：将系统切到 USB 下载模式（掩膜 ROM 的
UBOOT1.00）并进入死循环，等待电脑端的刷写工具接入。此时手柄对外表现为
一个 USB 大容量存储设备 `BR23 UBOOT1.00`。

这也是为什么**要按住约 3 秒**——短按只会关机，不会进刷写模式。

详见 [boot-mode-logic.md](boot-mode-logic.md)。

## 常见问题

**Q: 按住组合键后手柄只是关机，没有出现新设备。**
- 确认是**数据线**（能跑数据，而非纯充电线）：正常模式下电脑能看到 Xbox 手柄就说明线没问题；
- 拔线重插后再试一次，组合键要按满 3 秒；
- 换一个 USB 口（优先 USB 2.0 直连口，避开扩展坞和前面的机箱口）；
- 关闭可能会拦截 USB 枚举的软件（USB 过滤器、杀毒软件外设防护等）后重试。

**Q: 设备管理器里出现了 `BR23 UBOOT1.00` 但工具说找不到设备。**
- 用**管理员权限**运行工具（Windows 需要管理员权限访问物理磁盘）；
- 等待 3~5 秒让 Windows 完成驱动加载再点「备份」。

**Q: 进了刷写模式但我不想刷了，怎么恢复？**
- 拔掉数据线再插上，或在工具中选「5. 退出手柄刷写模式」；
- 手柄会重启回正常模式（Xbox 手柄）。
